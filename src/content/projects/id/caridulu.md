## Ringkasan Proyek

Proyek tugas akhir ini membangun Caridulu, website pencarian produk untuk membandingkan barang dari berbagai marketplace besar di Indonesia. Saat ini mendukung Shopee Indonesia, Tokopedia, dan Lazada Indonesia, sehingga pengguna bisa membandingkan penawaran lintas platform dalam satu tempat.

## Tanggung Jawab Utama

- **Web Scraping Data Produk**: Memakai Python dan BeautifulSoup untuk menarik hasil pencarian produk dari beberapa marketplace — nama produk, harga, rating, jumlah terjual, lokasi penjual, gambar, dan URL.
- **Pengembangan Frontend**: Memakai React + Vite untuk membangun antarmuka yang responsif dan interaktif, menampilkan hasil pencarian dari proses scraping lintas marketplace.
- **Pengembangan Backend**: Membangun backend dengan FastAPI sebagai penghubung antara frontend dan proses scraping.
