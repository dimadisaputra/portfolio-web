## Ringkasan Proyek

Tujuan proyek ini menarik tautan artikel dari lebih dari 1000 portal media online — CNN Indonesia, Kompas.com, Detik.com, dan lainnya. Proyek ini memakai Scrapy Framework untuk proses scraping. Data yang terkumpul diubah ke format JSON, JSONL, CSV, atau XLSX dan disimpan di data buffer untuk diproses lebih lanjut.

## Tanggung Jawab Utama

- **Pengumpulan Data**: Memakai Scrapy untuk crawling dan scraping tautan artikel berita dari lebih dari 1000 portal media online.
- **Pengolahan Data**: Mengubah data yang terkumpul ke format yang dibutuhkan (JSON, JSONL, CSV, XLSX).
- **Penyimpanan Data**: Menyimpan data di buffer untuk diproses lebih lanjut.

## Teknologi

- Python
- Scrapy Framework
