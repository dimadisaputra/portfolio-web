## Ringkasan Proyek

Trippedia App adalah aplikasi desktop untuk keperluan manajemen penawaran klien di perusahaan Trippedia Perkasa. Aplikasi ini dirancang untuk menyederhanakan dan mempercepat pembuatan proposal perjalanan, baik untuk custom offer, open trip, maupun private trip. Tujuannya menaikkan efisiensi operasional lewat satu alat terpusat untuk semua hal yang berkaitan dengan penawaran.

## Tanggung Jawab Utama

- **Pengembangan Fitur Inti**: Merancang dan membangun fungsi utama aplikasi untuk membuat, menyunting, dan mengelola berbagai jenis paket perjalanan secara dinamis.
- **Manajemen Data**: Membuat modul untuk menampilkan informasi penting seperti profil perusahaan, detail armada transportasi, dan riwayat lengkap klien beserta pesanannya.
- **Desain Antarmuka**: Membangun UI yang interaktif dan responsif dengan React, dengan state management yang rapi lewat Redux.
- **Arsitektur Desktop**: Memakai Electron.js untuk membangun aplikasi desktop lintas platform dari basis kode web (JavaScript, HTML, CSS).
- **Database Lokal**: Merancang dan mengelola database lokal dengan SQLite untuk menyimpan data penawaran, informasi klien, dan detail penting lain langsung di perangkat pengguna.
